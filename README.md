# Blinkit Frontend Clone

A responsive frontend clone of the **Blinkit** quick-commerce web application, built using HTML5 and CSS3. 

---

## 🚀 Features

* **Navigation Bar (`<nav>`):**
  * Brand logo with custom color styling (`blinkit`)[cite: 1, 2].
  * Delivery time estimation indicator ("Delivery in 16 minutes") with location details (Ved Vyas Puri, Saharanpur)[cite: 1].
  * Interactive search bar with placeholder text ("Search 'Chocolate'")[cite: 1, 2].
  * User login anchor and styled cart button[cite: 1, 2].
* **Promotional Banner & Cards:**
  * Featured essentials banner image[cite: 1, 2].
  * Promotional grid cards for Pharmacy, Pet Care, and Baby Care[cite: 1, 2].
* **Product Categories Grid:**
  * Multi-column grid layout (10 columns) showcasing various shopping categories ranging from dairy, fresh fruits, and vegetables to cleaning and personal care essentials[cite: 1, 2].
* **Detailed Footer:**
  * Multi-column layout featuring useful links, partner resources, corporate initiatives, and comprehensive category lists[cite: 1, 2].
  * App download section with placeholder buttons for App Store and Google Play[cite: 1, 2].
  * Social media icons and legal disclaimer section[cite: 1, 2].
